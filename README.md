# Calculadora de Mensagens - Java POO

Projeto em Java para calcular faturas de envio de mensagens (E-mail e SMS), desenvolvido como atividade prática de Ciência da Computação para treinar Programação Orientada a Objetos.

## 🛠️ Conceitos Praticados
- **Herança** (`extends` e `super`)
- **Polimorfismo** (Processamento em um único vetor `Mensagem[]`)
- **Sobrescrita** (`@Override`)

## 📋 Regras de Negócio
- **E-mail:** R$ 0,02 por envio (10% de desconto se passar de 1000 envios).
- **SMS:** R$ 0,15 por envio (sem descontos).
- **Limite:** O programa avisa se a fatura final passar de R$ 100,00.

## 🚀 Como Executar
Basta baixar/clonar o repositório, abrir o arquivo `Main.java` em qualquer IDE (como IntelliJ ou VS Code) e rodar.
